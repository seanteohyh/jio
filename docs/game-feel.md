# Game Feel

> The north star for anything with "character" — celebrations, streaks,
> awards, icons, motion. Settled in the UX review (item #22), 2026-08-29.
> A firm constraint, not a soft guideline: check new work against it before
> shipping, don't retrofit it after.

---

## 1. The sentence

> Deciding lunch together should feel like a small shared ritual between
> Kakis, not one more task to close out.

Everything below exists to serve this one sentence. If a proposed feature —
an animation, a stat, a badge — doesn't make deciding lunch feel more like a
shared ritual and less like a chore, it doesn't belong here regardless of how
polished it is on its own.

---

## 2. The hard line: no leaderboards

**No public ranking or comparison of Kakis against each other, ever.** This
is permanent, not a "not yet." Kaki Awards, food-identity stats, and any
future feature shaped like them stay **personal-progression and
community-presence only** — what a Kaki celebrates about itself, never how
it stacks up against another one. A leaderboard turns "ritual between
friends" into "task to win," which is exactly the failure mode the north
star exists to rule out.

---

## 3. The four-pillar mapping

The sentence is abstract enough to need a translation into what actually
gets built. Four pillars, each already anchored to a real, shipped (or
planned) piece of the app:

| Pillar | What it means here | Where it lives |
|---|---|---|
| **Motivation** | Progress that's personal, not competitive | Food-identity cards and Kaki stats — locked monthly snapshots of *your* (or *your group's*) own history, never someone else's |
| **Education** | Teaching the ritual to people who don't know it yet | The first-timer onboarding fix (Item 2/3A–3D) — pre-filled invite lists, a signed-out preview, the first-decided celebration |
| **Advocacy** | Giving people something worth showing off | The shareable food-identity/chop card — an artifact designed to leave the app, not just live in it |
| **Community** | Small, shared, group-facing motifs | The order-chit redesign and the Kaki Award motif (#20's icon work) — things a group experiences together, not things one person accumulates alone |

---

## 4. How to use this

Before shipping anything in #20 (icon language), #21 (micro-interactions),
#24 (Kaki page), #25 (celebration/chit redesign), or any future feature in
the same "character work" family, check it against §1–§3 above:

- Does it read as a *ritual* (warm, small, shared) or a *task* (a bar to
  clear, a number to beat)?
- Does it compare people/groups to each other, even implicitly? If yes, cut
  it — see §2.
- Which pillar is it actually serving? If none of the four, it's probably
  scope creep, not a Game Feel feature.

This file is the reference for that check — update it if the north star
itself ever changes, but don't quietly drift from it feature by feature.
